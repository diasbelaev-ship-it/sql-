# GymFinder Алматы — памятка для знакомства и подготовки отчёта

Подготовлено 11 ноября 2026 года. Сначала прочитайте этот файл и `README.md`, затем изучайте исходники и SQL-файлы. Это актуальное описание текущего состояния проекта; документы с датой в названии могут описывать более раннюю версию интерфейса.

## Кратко о проекте

GymFinder — веб-сайт для поиска залов Алматы. Пользователь задаёт бюджет и предпочтения, смотрит варианты списком или на карте, сравнивает абонементы и сохраняет залы. Встроенный помощник принимает команды обычным языком и может управлять разрешёнными функциями сайта.

## Что умеет сайт

- Искать залы по названию и адресу.
- Фильтровать по категории посетителя, цене за 30 дней, сроку абонемента, району и ценовому сегменту.
- Сортировать каталог по цене, названию и расстоянию.
- Показывать залы на карте Leaflet/OpenStreetMap и искать поблизости после разрешения геолокации браузером.
- Открывать карточки с адресом, тарифами, ссылками на источники цен и пользовательскими отзывами.
- Сравнивать до трёх выбранных залов с учётом активных фильтров и срока тарифа.
- Сохранять залы в аккаунте, оставлять и редактировать отзыв после входа.
- Принимать запросы к помощнику Gemini: подбор и фильтры, карта, карточка, сравнение, избранное, подготовка отзыва. Публикация отзыва требует подтверждения пользователя.
- Использовать краткий локальный режим, когда Gemini недоступен.
- Показывать документацию возможностей на `/guide` и SQL-витрину на `/sql`.

## База и данные

В PostgreSQL разделены две схемы: `almaty_gym` для SQL-кейса и `gym_web` для функций сайта. SQL-кейс включает 70 залов и связанные тарифы и учебную активность. Названия и адреса залов связаны с открытыми страницами клубов. Пользователи, отзывы, тренеры, занятия, платежи и бронирования SQL-кейса — тестовые данные, а не реальные аккаунты или подтверждённые услуги.

В каталоге есть опубликованные тарифы и расчётные оценки; отчёт должен разделять эти категории. Длинные сроки абонементов рассчитываются из базовой месячной цены и не означают, что клуб продаёт такой тариф. Для 67 залов есть координаты, связанные с источниками, ещё 3 точки не используются для точного поиска рядом. Районы Алматы назначены ориентировочно.

## Локальный запуск

1. Установите Node.js 22.13+ и PostgreSQL 18. Если бинарные файлы PostgreSQL лежат не в `C:/Program Files/PostgreSQL/18/bin`, задайте `PG_BIN`.
2. Выполните `npm ci`.
3. Выполните `npm run site:start`. Скрипт поднимает локальную БД, загружает SQL-данные при первом запуске, применяет миграции и запускает сайт.
4. Откройте `http://127.0.0.1:3000`.

`npm run dev` запускает режим разработки. `npm run build` создаёт production-сборку. Настройки подключения описаны в `.env.example`. Реальный `.env.local` с паролями и API-ключом в этот архив намеренно не включён. Без Gemini ключа сайт открывается, а помощник отвечает в локальном режиме. Для Gemini задайте серверный `GEMINI_API_KEY`; страницу настройки можно открыть только с localhost.

## Проверки и ограничения

Последняя production-сборка перед упаковкой завершилась успешно и прошла проверку TypeScript. Автотесты при подготовке архива не запускались. Модульные тесты запускаются командой `npm test`; `npm run test:api` требует запущенный сайт. Команды `npm run test:ai:live`, `npm run test:ai:actions` и `npm run test:ai:terms` выполняют живые запросы Gemini, требуют действующий ключ и могут расходовать квоту.

При подготовке отчёта различайте реализованные функции, ограничения данных и идеи из документов. Не называйте расчётную цену предложением клуба, учебную запись — реальным отзывом, а ориентировочную координату — точным адресом. Даты и результаты старых отчётов сверяйте с текущим кодом.
