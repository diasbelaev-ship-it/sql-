# Сайт GymFinder Алматы

Текущая реализация следует фазам сайта из прежнего плана с новым объёмом базы, который пользователь уточнил: 1000+ строк суммарно, реальные залы Алматы. SQL-кейс использует 10 таблиц и 2460 строк после миграции 005; отдельная схема gym_web хранит реальные действия посетителей сайта.

- [x] Next.js App Router, TypeScript strict, PostgreSQL и параметризованный SQL.
- [x] Поиск по названию/адресу, аудитории, бюджету за 30 дней, сроку, городской зоне, ценовому сегменту и происхождению цены.
- [x] Сортировки, пагинация, фильтры в URL, пустые состояния и ошибки подключения.
- [x] Страница зала, тарифы, источники, демонстрационное расписание.
- [x] Карта Leaflet/OpenStreetMap и приблизительные расстояния с отметкой погрешности 8 км.
- [x] Регистрация, вход, bcrypt, opaque cookie, срок сессии 8 часов и отзыв доступа при выходе.
- [x] Избранное в PostgreSQL, отзывы пользователей, сравнение до 3 залов.
- [x] Бесплатный помощник по правилам: категория, бюджет, срок, зона, источник цены, уточнение/сброс и сравнение предыдущей выдачи.
- [x] История чата и фильтры в PostgreSQL, проверка владельца сессии, сериализация запросов одного чата.
- [x] Адаптивный интерфейс, проверка desktop/mobile, TypeScript, production build, API-проверки.

## Расширение сроков абонемента

В каталоге предусмотрены 1, 2, 3, 6, 9 месяцев, год и любой срок. Миграция 005 добавляет 840 вариантов на 60/90/180/270 дней: полная цена равна цене за 30 дней × число месяцев, без скидок. Все новые варианты — учебные оценки с источником NULL, включая расчёты от опубликованной месячной цены. После полной загрузки: 1060 тарифов (1046 оценок и 14 опубликованных), 2460 строк в десяти таблицах. Бюджет остаётся за 30 дней; полный платёж показывается отдельно.

- [x] Идемпотентная миграция 005 для новой и существующей базы с сохранением тарифов и данных сайта.
- [x] Миграция 005 применена к существующей базе; повтор сохранил 1060 тарифов и 2460 строк, SQL-проверка прошла.
- [x] Свежая загрузка `run_all.psql`, `verify.sql` и повтор миграции в отдельной временной базе; контрольная сумма тарифов сохранена, временная база удалена.
- [x] `npm run test:terms`: все 12 сочетаний трёх категорий и четырёх новых сроков, бюджет, происхождение цены и сравнение позиций [3,1] проверены на реальной базе.
- [x] Живой Gemini: запрос на два месяца дал `2months` и карточки по 60 дней; сравнение первого и третьего сохранило срок.
- [x] Встроенный браузер: семь вариантов срока, двухмесячный тариф с полной ценой 30 000 ₸ за 60 дней. Playwright: 1440/1024/768/390/320, сравнение, источник цены, пустая выдача и восстановление; без переполнения и ошибок.

- [x] Финальные снимки с живым ответом Gemini при ширине 1440/390 после исправления прокрутки: начало ответа видно, горизонтального переполнения нет.

Первоначальная ошибка 401 устранена: причиной было распознавание ключа со скриншота, после точного ввода того же ключа Google принял запросы. Живая генерация подтверждена отдельно от тестового транспорта. Подробности: `GEMINI_ASSISTANT.md`.

Поиск по реальному времени работы и точный радиус не включены: исходные данные содержат учебные занятия и приблизительные точки, а проверенного полного расписания клубов нет. Для этих функций сначала нужны реальные часы работы и геокодирование 70 адресов. Помощник поддерживает Gemini; резервный режим работает по правилам. Стоимость и квоты внешних запросов зависят от настроек проекта Google.

Локальные сессии сайта сохраняются в PostgreSQL. Это заменяет запланированный ранее реестр в памяти: перезапуск сервера не отзывает вход до истечения 8 часов. Учебные записи clients/reviews не являются аккаунтами или отзывами пользователей сайта.
